# Portfolio Insight Examples

This document contains sample portfolio insights for testing the Portfolio Insight feature.

The examples explain portfolio changes using holding data and market information. The insights should be simple and easy for users to understand.

## Points to Check

While generating a portfolio insight, the system should check:

- Overall portfolio profit or loss
- Stocks with high gain or loss
- Market movement
- Sector performance
- User risk profile
- User preferred language

## Sample Portfolio Insights

### Example 1

**English:**

Your portfolio increased today because most of your IT holdings performed well. The IT sector also showed positive movement.

**Hindi:**

आपके पोर्टफोलियो में आज बढ़त हुई क्योंकि आपकी अधिकांश IT होल्डिंग्स ने अच्छा प्रदर्शन किया। IT सेक्टर में भी सकारात्मक बढ़त देखी गई।
