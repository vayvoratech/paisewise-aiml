# Hindi Translation Review Checklist

## Translation Rules

- Financial meaning must remain accurate.
- Avoid literal word-for-word translation.
- Use simple Hindi understandable by beginners.
- Keep English financial abbreviations (SIP, NAV, CAGR) unchanged.
- Avoid technical jargon where possible.
- Maintain consistency across all terms.

## Review Checklist

- [ ] Meaning is correct
- [ ] Beginner friendly
- [ ] Grammatically correct
- [ ] Financial context preserved
- [ ] English abbreviation retained if necessary
- [ ] No ambiguity
