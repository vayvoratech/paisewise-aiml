# Knowledge base sources

The conversational assistant knowledge base contains the 30 local lesson files, the local financial jargon definitions, PaiseWise product FAQ material, mutual-fund category education and a short financial-education reference based on SEBI investor-education material.

External references used for the educational reference:
- SEBI National Strategy for Financial Education: https://investor.sebi.gov.in/pdf/policy-documents/FinalNSFE.pdf
- SEBI Financial Education Booklet: https://investor.sebi.gov.in/pdf/downloadable-documents/Financial%20Education%20Booklet%20-%20English.pdf
- AMFI mutual-fund categorisation: https://www.amfiindia.com/investor/knowledge-center-info?zoneName=CategorizationOfMutualFundSchemes

The assistant must not turn these educational sources into personalised investment advice.
