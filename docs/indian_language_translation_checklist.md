# Indian Language Translation Checklist

## Supported languages

The service supports all 22 languages in `data/indian_languages.csv`.

For every translated financial explanation, review:

- [ ] Financial term is preserved accurately.
- [ ] Meaning is not changed by translation.
- [ ] Beginner-friendly wording is used.
- [ ] No guaranteed return or prediction is introduced.
- [ ] Numbers, percentages and financial units remain correct.
- [ ] One simple example is understandable in the target language.
- [ ] The selected language matches the user's language selection.

Hindi remains the original Week 2 checklist target. The same quality checklist
now applies to all 22 supported Indian languages.
